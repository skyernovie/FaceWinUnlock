「凭什么他能刷脸，

同桌那台笔记本自带红外摄像头，开机看一眼就进桌面。 我这台性能拉满，摄像头却不支持 Windows Hello，每天还得敲那串密码。

贰 · 功能

四件事，做到位

每一项都直接对应锁屏上真实发生的一步，不是演示图。

01

系统级凭据注入WINLOGON CREDENTIAL

向 Windows 自定义凭据提供程序注入 DLL，登录凭据由系统自己校验，不改登录界面，也不打补丁。

02

本地 2D DNN 识别OPENCV · ONNX

模型随程序内置，特征提取与人脸比对都在本机跑。整个过程不发起任何外部请求。

03

活体检测防照片ANTI-SPOOFING

对着屏幕上的照片、手机里的合影，识别不会通过。只有真人出现在镜头前才放行。

04

全程离线OFFLINE BY DEFAULT

人脸数据只落本地数据库。断网、飞行模式、局域网封闭环境，解锁都不受影响。
