历史版本。

从 0.3.4 到当前版本，每次改动按时间倒序留档。

完整发布说明见 GitHub Releases

0.4.1 2026-11-14 最新 功能添加 · 性能优化 · 修复
  • 修复占用异常：识别主循环空闲时没有休眠，空转占满单核，导致 dwn.exe / LogonUI.exe 高占用与风扇狂转；现改为空闲时休眠 100ms 等待触发。
  • 解锁提速：识别模型改为全局缓存（省去每次数百毫秒加载）、摄像头会话复用（省去每次重新打开 1–2 秒）、一帧完成全用户匹配，不再逐个用户串行扫描。
  • 新增深色模式。
  • 新增旋转摄像头功能。
  • 移除锁屏界面的文字提示，改为动画 + 少量文字显示（等待触发 / 解锁成功 / 解锁失败）。
0.4.0 2026-10-01 功能添加 · 系统增强 · 修复
  • 本次更新改动较大，建议先看 B 站视频教程。
  • 新增密码加密存储。
  • 大幅加快面容识别启动速度，与锁屏界面同步。
  • 修复用户名或密码错误时给 LSA 多发一次凭据的问题（概率触发）。
  • 修复面容识别较慢时导致 DLL 无法安全卸载的问题（概率触发）。
  • 彻底修复开机面容触发器、管道错误、手动解锁后摄像头的一系列问题。
  • 优化初始化第 2 步的进度条，大幅加快第 2、3 步速度。
  • 移除开机面容识别开关、解锁服务开关与服务日志。
  • 更新前请先卸载旧版，更新后需重新初始化。

  • 小幅优化首选项界面的内存占用。
  • 本版本需要重新初始化。
